# 页面预加载

常用入口 Resources、My uploads、Upload resource 在页面可见、联网且空闲后开启完整路由预取，首次延迟至少 700 ms。Next.js 继续根据链接是否进入视口调度并去重请求。

资源列表只对前 3 条详情启用空闲预取，其余详情保留鼠标悬停、键盘聚焦、触摸时预取。预取内容为页面与元数据，不请求签名下载链接或文件正文。离线、省流量、slow-2g/2g/3g 时禁用自动空闲预取，正常导航和操作意图预取保留。

2026-11-10 验证：118 项单元测试通过，lint、类型检查和严格生产构建通过。Edge 使用隔离数据库与合成资源验证：自动预取恰好 3 条详情及常用入口；点击已预取详情没有新增该页面的 RSC 请求；省流量模式自动详情预取为 0；浏览器无未处理错误。该验证说明缓存复用，不代表生产 P95 性能指标已达标。
