# 页面预加载

## 管理员后台（2026-11-12）

后续按界面精简要求，桌面侧栏、手机菜单及 Dashboard 页面只保留 Dashboard 管理入口，移除 Reports / Audit log 导航和页签。因此常规页面空闲时仅预加载 Dashboard；既有举报和审计接口继续用于治理能力，以下三个入口验证记录描述精简前状态。

Java 分支新增 `/admin/dashboard`，并为 Dashboard、Reports、Audit log 三个入口开启空闲及悬停/聚焦/触摸预加载。仅管理员启用；省流量、慢网、离线或页面不可见时不自动预加载。Dashboard 默认准备 `range=7d`，其他范围在切换意图时准备。三个后台元数据接口与正式导航共享请求及 30 秒标签页内缓存，管理写操作、显式刷新、退出、401/403 或停用响应会清除缓存；不持久化后台数据。

Dashboard 采用真实数据库汇总：当前资源数（排除 deleted）、发布数、注册用户数（含停用）、待处理举报、资源元数据大小（非对象存储占用）；趋势包含创建上传及文件大小、创建/处理举报，排行包含资源状态、已发布标签/类型、期间审计动作。历史上传包含保留的 deleted 记录。24h/7d/30d 分别为包括当前 UTC 小时/日期的 24/7/30 个桶，当前桶不完整；无活动补零。全量当前汇总不随时间筛选变化，新增及历史曲线随范围变化。刷新失败保留上一份快照并明确提示。没有新增流量采集、下载统计或数据库表。

本轮验证：70 项 Java 测试（含隔离 PostgreSQL 集成）全部通过，32 项前端/会话/缓存测试通过，修改的前端文件 ESLint 零警告；本地源码快照完成生产 JAR 构建。Edge 合成接口检查覆盖管理员三入口缓存复用、普通用户无后台预取、省流量不自动预取、时间范围切换、空数据、刷新失败与重试，以及 1600/390 宽度布局。浏览器截图使用演示数据，未访问生产数据库或外部服务；本轮未部署。

> 当前 Java + 原生 JavaScript 版本保留原版的预加载入口，并在当前标签页内复用页面元数据。资源、标签、列表及用户展示信息有效期 30 秒，公开配置有效期 60 秒，最多保留 24 项；命中后可重复使用。不持久化凭据，不签发下载链接，也不读取文件正文。具体部署缓存规则见 [迁移 PRD](JAVA-MIGRATION-PRD.md) 与 [部署环境](DEPLOYMENT-ENVIRONMENT.md)。

常用入口 Resources、My uploads、Upload resource 在页面可见、联网且空闲后开启预加载，首次延迟至少 700 ms。Resources 提前准备标签和首屏列表，My uploads 提前准备工作区列表；这些入口同时准备公开配置和用户展示信息，避免切换时串行等待初始化请求。Upload resource 的页面代码已经随应用加载，因此不额外请求业务数据。

预取和实际访问共享正在进行的请求。地址去重仅在请求进行期间生效，过期或失败后可再次预取。单个页面离开只取消自己的等待；仍有预取或其他页面使用结果时保留共享请求。已完成的数据不因一次点击而删除；每次读取返回独立副本，表单编辑不会污染缓存。

搜索提交、筛选变化、重试和上传扫描轮询强制读取最新结果；修改、删除、上传、举报等写操作及显式刷新清除缓存。退出登录、收到未授权或账号停用响应时清除缓存；退出登录还清除页面恢复状态。缓存不进入 HTTP 缓存、Service Worker、Web Storage 或 IndexedDB；所有写操作、下载及未命中缓存的业务请求仍由服务端验证身份和权限。

客户端切换准备完整目标页面后一次提交，避免先显示空壳再补数据；超过 150 ms 才显示顶部加载进度。首次访问、缓存过期和未预取的页面仍可能需要网络等待。

资源列表只对前 3 条详情启用空闲预取，其余详情保留鼠标悬停、键盘聚焦、触摸时预取。预取内容仅为页面元数据，不请求签名下载链接或文件正文。离线、省流量、slow-2g/2g/3g 时禁用自动空闲预取，正常导航和操作意图预取保留。
